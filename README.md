# Cafe Ordering System

A Spring Boot system for managing cafe orders, inventory, and ingredient deduction.

## Features
- Order management by cashier
- Automatic inventory deduction (ingredients per product)
- Menu management
- Real-time order processing

## Example
Ordering an omelette deducts:
- 2 eggs
- 15g tomato paste

## Tech Stack
- Java
- Spring Boot
- JPA
- REST APIs
